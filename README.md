# z3-Anti-hash

**z3-Anti-hash** is a lightweight Python tool designed for hash auditing and matching across multiple algorithms including **MD5, SHA-1, SHA-512**, and more.

## Features
* **Multi-Algorithm Support:** Works with standard cryptographic hashes (`MD5`, `SHA-1`, `SHA-256`, `SHA-512`, etc.).
* **Dynamic Word Generation:** Generates candidate strings on the fly without requiring massive external wordlists.
* **Lightweight & Resource-Friendly:** Low memory footprint — runs smoothly on standard hardware without needing a powerful PC or dedicated GPU.

## Disclaimer
This project was created strictly for **educational purposes**, algorithmic benchmarking, and authorized security testing (CTFs).
